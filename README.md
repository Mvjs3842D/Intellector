🧠 Intellector

An AI-powered teaching assistant that adapts its responses based on the type of question — either giving direct answers or guiding users through Socratic learning.

🚀 Features
⚡ Direct answers for factual questions
🎓 Guided learning for conceptual topics
📊 Tracks user understanding (0–5 scale)
💬 Chat history with auto-generated titles
🔌 Works with local LLM via Ollama

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Flask (Python)
AI: Ollama (local models)

📌 Note
No database (in-memory storage)
Requires Ollama running locally
